A program that writes one single-line safety warning label for every human being — "CAUTION: Contents under pressure. Will say 'yes' to every plan, then spend the whole week quietly hoping it gets cancelled." (123 characters) — to `/output/entry.txt`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

Python 3.13, standard library only, no network, deterministic (the same fixed label every run, so both grading runs produce identical bytes).

## Files

- `main.py` — the entrypoint; writes the warning label to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` in the grader's container).
- `LICENSE` — MIT.
